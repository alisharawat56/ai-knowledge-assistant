
# Example Questions and Answers

The following examples illustrate the intended behavior of the AI Knowledge Assistant.

## Example 1: Python Modules

**Question:** What is a Python module?

**Expected answer:** A Python module is a file containing Python definitions and statements. Modules allow related code to be organized and reused by importing them into other Python programs.

**Expected source:** modules.md

## Example 2: Python Lists

**Question:** What does append() do in Python?

**Expected answer:** The append() method adds a single item to the end of an existing list. It modifies the original list and returns None.

**Expected source:** data_structures.md

## Example 3: Unsupported Question

**Question:** How do I make sourdough bread?

**Expected behavior:** The assistant should indicate that the available Python documentation does not contain sufficient evidence to answer the question.

**Expected source:** No supporting source should be presented as evidence.

## Note

These are reference examples, not verified transcripts from a particular model run. Actual generated answers should be checked against their retrieved passages.
